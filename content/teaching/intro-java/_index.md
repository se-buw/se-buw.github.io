**This site presents the slides and example code of the course Introduction to Programming with Java at [Bauhaus University Weimar.](https://www.uni-weimar.de)**

The course teaches programming from the first program through methods, arrays, classes, inheritance and interfaces to graphical user interfaces with JavaFX. Every lecture comes with example programs that you can open, run and explore.

## Slides

- [All lectures](slides/): slides in the browser (HTML) and as PDF

Lectures are added here as they are released during the semester. Code listings on the slides have a copy button and an "Open in VS Code" button that opens the listing in your copy of the example code.

## Example Code

The example programs are in the repository [se-buw/intro-java-code](https://github.com/se-buw/intro-java-code), one folder per lecture:

```bash
git clone https://github.com/se-buw/intro-java-code.git
```

Open `course.code-workspace` in VS Code. Run `git pull` to get the code of new lectures. The [README](https://github.com/se-buw/intro-java-code#readme) explains the setup: a current JDK (the version used in the course is given there and in the first lecture).
