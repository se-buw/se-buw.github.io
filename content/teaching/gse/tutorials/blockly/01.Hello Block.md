We create a simple block that has two inputs, which can be set by the user. The first input determines how many times the greeting is printed. The second input determines who to greet.

The executable example is available as <a href="../dist/01.helloBlock" target="_blank">hello block language</a>..


Setting up the workspace happens in ``index.html``.
