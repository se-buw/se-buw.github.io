This project overview refers to folder `01.helloBlock` in the [code examples repository](https://github.com/se-buw/blockly-intro).

We create a simple configurable Hello World block that has two input fields, which can be entered by the user. The first input determines how many times the greeting is printed. The second input determines who to greet.

The executable example is available as <a href="../dist/01.helloBlock" target="_blank">hello block language</a>.

## Setting up the workspace and visual editor

To make the new block available in the workspace, we need to initialize a Blockly editor. We do this in source file `src/main.ts`. The first step is to import the block definition from `blocks.ts` and register it with Blockly by executing the function `defineBlocks()` in line 5, below.

{{< sub-code 
  file="code-examples/blockly-intro/01.helloBlock/src/main.ts" 
  lang="typescript" 
  start="1" 
  end="15" 
  linenos="true"
>}}

The workspace is initialized in line 8 by calling the function `Blockly.inject()`. This function takes two parameters: the first parameter is the id `blocklyDiv` of the HTML element in which the workspace should be rendered (below), and the second parameter is an object that defines various options for the workspace. In this case, we specify that we want to use a flyout toolbox with the content defined in a JSON array from line 11 to line 13. The toolbox contains a single entry of `kind` `block` of type `greeting`, which is the block we defined in `blocks.ts`.

The HTML element `blocklyDiv` is defined in line 16 of file `index.html`. This file also loads our TypeScript code in file `src/main.ts` in line 21.

Blockly provides a code generation framework and code generators for various programming languages. We now implement a custom code generator to generate pseudo code.
