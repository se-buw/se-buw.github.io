## Installation of Node.js and npm

To follow the tutorials, you need to have [Node.js installed](https://nodejs.org/en/download) on your machine. There are various options on how to install it. For Windows the easiest way is to download a pre-built installer (lower part of the download page). 

Here are some alternative instructions for installing Node.js on different platforms from the command line:
- **Windows**: 
```
winget install OpenJS.NodeJS.LTS
```
- **macOS**: 
```bash
brew install node
```
- **Linux**: 
```bash
sudo apt install nodejs npm
```

After the installation you can run the following commands to check whehter everything is installed:
```bash
node -v
npm -v
```
This could print something like:
```
> node -v    
v24.14.1
> npm -v 
11.11.0
```

## Obtaining the code examples
The code examples for the different steps of the tutorial are available in a [GitHub repository](https://github.com/se-buw/blockly-intro). You can either clone the repository using `git` or [download it as a ZIP file](https://github.com/se-buw/blockly-intro/archive/refs/heads/main.zip) and extract it on your machine.

In a terminal navigate to the root of the project folder and run the following command to install the dependencies and build the project (the subprojects will be built by this command):
```bash
npm install
npm run build
```

## Choosing an Editor

You can use any code editor you like. A good choice (also used throughout this tutorial) might be [Visual Studio Code](https://code.visualstudio.com/).

## Running the examples

To check whether everything is set up correctly and to run the examples in a development server, you can navigate to the project you want to run (currently `01.helloBlock`, `02.helloBlocks`, or `03.turtle`). In each folder, you can run the following command to start a development server:
```bash
cd 01.helloBlock # navigate to project from root folder
npm install # if you didn't do this before
npm run dev
```
The `npm run dev` command should start the development server and tell you how to access the running project from your browser as shown in the example output below:
```
  VITE v8.0.10  ready in 153 ms

  ➜  Local:   http://localhost:5173/
  ➜  Network: use --host to expose
  ➜  press h + enter to show help
```
