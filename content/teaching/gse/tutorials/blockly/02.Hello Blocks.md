This project overview refers to folder `02.helloBlocks` in the [code examples repository](https://github.com/se-buw/blockly-intro).

In this project, we slightly extend the previous example of the `greeting` block. We change the input fields to be input values. This allows us to define the values in terms of other blocks, which can be connected to the input fields. We add a block for text and one for numbers from the blockly library.

The executable example is available as <a href="../dist/02.helloBlocks" target="_blank">hello blocks language</a>.

The first change is in line 7 where we renamed the block type to `greeting_external` to distinguish it from the original `greeting` block. The attribute `message0` in line 8 remains unchanged, as the placeholders `%1` and `%2` are still used to indicate the positions of the input fields. The main change is in the definition of the input fields in lines 10-19. Instead of defining fields, we now define value inputs (type `input_value`) with names `TIMES` and `SUBJECT`. We add `check` attributes to specify the types of blocks that can be connected to these inputs. For the `TIMES` input, we specify that only blocks producing `Number` can be connected. For the `SUBJECT` input, we specify that only blocks of type `text` can be connected.
