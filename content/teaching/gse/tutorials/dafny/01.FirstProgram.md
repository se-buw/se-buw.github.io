## Dafny on the Formal Methods Playground

For this first program, we will not install Dafny yet, instead we will use the [Formal Methods Playground](https://play.formal-methods.net/). This is a web-based environment that allows you to write and verify Dafny programs and other specifications without any installation. Make sure to select the **Dafny** tool in the top dropdown menu of the playground.

Some of the features of the playground, e.g., login and history management, are described in this playlist: [Formal Methods Playground](https://www.youtube.com/playlist?list=PLGyeoukah9NYq9ULsIuADG2r2QjX530nf).

Note that we have to first assign the return value of the call `GetHelloWorld("de")` to a new variable `text` in line 13 before we can print it in the `Main` method. This is because Dafny does not allow to use a method call directly in an expression.

You will find that [this extended program](https://play.formal-methods.net/?check=DFY&p=watch-puzzle-shirt-shut) fails to run. The error message produced tells us that the element `langCode` in line 9 may not be present in the domain of the map `greetings`. While other programming languages would simply throw an exception at runtime, Dafny is a verification-aware programming language and thus requires us to prove that the program is correct. In this case, we need to insure Dafny that the element `langCode` for the lookup in line 9 is  present in the domain of the map `greetings`.

## Verification-aware programming

Dafny is a verification-aware programming language. It automatically attempts to verify some correctness properties of programs. These include the absence of runtime errors, e.g., invalid lookups in maps. We can tell Dafny that it may assume that whenever the method `GetHelloWorld` is called, the argument `langCode` is within the set `{"en", "es", "fr"}`.
