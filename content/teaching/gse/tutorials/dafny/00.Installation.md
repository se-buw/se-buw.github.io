We will cover different ways to use Dafny and the Dafny compiler. 

## Dafny in the browser

The easiest way to get started without an installation is to use [Dafny on the Formal Methods Playground](https://play.formal-methods.net/?check=DAFNY). It allows you to write Dafny code and run it in your browser.

## Dafny in Visual Studio Code

For more complex interactions and development workflows, it might be best to install Dafny in [Visual Studio Code](https://code.visualstudio.com/). You can install the [Dafny extension](https://marketplace.visualstudio.com/items?itemName=dafny-lang.ide-vscode) from the Visual Studio Code marketplace.

## Dafny on the command line

For more advanced uses, e.g., to automatically run code generation to different target languages, you should install Dafny on the command line. You can find the installation instructions in the [Dafny Website](https://dafny.org/dafny/Installation).
