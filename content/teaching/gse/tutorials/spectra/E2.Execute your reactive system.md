This module connects specifications to executable software: read inputs, update controller state, and consume outputs inside Java.

## What you learn

- The minimal API calls needed to execute a synthesized controller.
- How controller I/O is represented as string-valued variable maps.
- How specification changes and runtime integration need to evolve together.

Spectra project on GitHub: https://github.com/jringert/spectra-tutorial/tree/main/E2_execution

Currently, synthesizing symbolic controllers is easiest done inside Eclipse. 

Execution workflow used in this module:

1. Synthesize a just-in-time symbolic controller.
2. Load it via `ControllerExecutor`.
3. Feed inputs as a map from variable names to string values.
4. Call `initState` for the first step and `updateState` afterwards.
5. Read system outputs with `getCurrValue`.

## How to work through this page

1. Run the base command-line simulator.
2. Verify outputs for a few input sequences.
3. Extend both model and simulator with `emergency`.
4. Recheck realizability and update guarantees if needed.

We also have an example project where this is done using a gradle task: https://github.com/se-buw/gendev.lab2/blob/main/build.gradle#L48
