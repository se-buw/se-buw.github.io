In this module, you practice `define`, type declarations, predicates, and arrays.

## What you learn

- When to use `define` versus `predicate`.
- How type aliases and arrays reduce duplication.
- How parameterized predicates improve readability and reuse.

`define` lets you name reusable expressions (for example, whether a car is waiting), so guarantees and assumptions stay compact.

Type aliases (`type Move = {...}`, `type Coord = Int(...)`) let you centralize domains and scale models with fewer edits.

Arrays reduce repeated variables (for example, `rob[0]`, `rob[1]`) and are indexed from zero.

Predicates package reusable constraints with parameters, such as motion updates or helper checks.
