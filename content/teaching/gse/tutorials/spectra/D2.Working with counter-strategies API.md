In this module we will use the API to generate counter-strategies for unrealizable specifications.

We will then create console applications with all dependencies packaged to run the Java/Spectra process externally.

## What you learn

- How to build a Java pipeline from parsing to realizability checking.
- How to generate and print concrete counter-strategies.
- How to compute cores programmatically and map them back to source lines.

## How to interpret results

- Counter-strategy output explains *how* the environment wins.
- Core output explains *which guarantees* are sufficient for failure.
- Using both together usually gives the clearest diagnosis.
