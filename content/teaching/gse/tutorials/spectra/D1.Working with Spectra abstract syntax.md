This module shows how to parse Spectra files outside the IDE and inspect the translated abstract syntax.

## What you learn

- How to parse a Spectra file into `GameInput`.
- Why kernel translation is important before analysis.
- How constraints are grouped by player and kind.

## How to read the output

- `env` constraints describe environment obligations.
- `sys` constraints describe system obligations.
- `aux` constraints are introduced during translation and help encode higher-level constructs.

The code for this part is available in the Spectra repository: https://github.com/jringert/spectra-tutorial/tree/main/D1_parsing
