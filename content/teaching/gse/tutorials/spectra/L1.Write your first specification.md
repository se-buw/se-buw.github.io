To create a new specification in Eclipse, first create a new Spectra project (`File > New > Other > Spectra Project`). This will create both a new project and a file with the same name and `.spectra` extension, where you can write your specification.

Every specification starts with the keyword `spec` followed by the name of the specification. The name should match the file name (without the extension). 

In the first step, we are going to write a specification for a simple traffic light controller that controls the lights on two lanes.
