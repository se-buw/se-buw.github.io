To create a new specification in Eclipse, first create a new Spectra project (`File > New > Other > Spectra Project`). This will create both a new project and a file with the same name and `.spectra` extension, where you can write your specification.

Every specification starts with the keyword `spec` followed by the name of the specification. The name should match the file name (without the extension).

## Spectra concepts

In Spectra, a specification describes a two-player game between the **system** (what we want to control and synthesize) and the **environment** (the external world).

**System variables** (`sys`) are outputs controlled by the system. **Environment variables** (`env`) are inputs controlled by the environment.

**Assumptions** (`asm`) describe the environment's behavior. **Guarantees** (`gar`) describe the system's obligations.

**Temporal operators** start every assumption or guarantee:
- `ini` (initial): must hold in the initial state only
- `alw` (always): must hold in every state
- `alwEv` (always eventually): infinitely often must reach a state where the condition is true

Here we use **bounded integers** (e.g., `Int(0..4)`) for robot coordinates and **enumerations** (e.g., `UP, DOWN, LEFT, RIGHT, STAY`) for movement commands.

The **`next` operator** (e.g., `next(rob[1]) = rob[1] - 1`) relates state variables across time steps. Importantly, you can only use `next` on environment variables in assumptions (the environment controls its variables), but you can use `next` on system variables in guarantees (the system is responsible for state updates).
