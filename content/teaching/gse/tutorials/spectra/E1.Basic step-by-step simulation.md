## What you learn

- How to inspect symbolic controllers interactively.
- How to switch between environment/system/both-player exploration.
- How to use logs and filters to debug larger state spaces.

## How to work through this page

1. Synthesize the controller.
2. Walk a few traces as environment player.
3. Repeat as both players.
4. Use logs to replay a run and inspect surprising behavior.

For this module, synthesize a **static symbolic controller** and explore it with the Rich Controller Walker (`Spectra Add-ons -> Rich Controller Walker`).

You can walk as environment, system, or both players, generate logs, replay logs, and filter visible next states using variable filters or full Spectra expressions.
