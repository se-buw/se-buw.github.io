In this module, you model trigger-based assumptions and guarantees.

## What you learn

- How trigger formulas capture bounded response behavior.
- How to read trigger clauses as timeline constraints.
- How to encode bounded absence from a state using triggers.

## Trigger intuition

A trigger expression relates an event pattern on the left to a required response pattern on the right, often with explicit bounds. This is useful for requirements like "if event X occurs, response Y must happen within N steps".

## How to work through this page

1. Read the traffic trigger examples to understand syntax.
2. Move to the grid model and identify where bounded behavior is needed.
