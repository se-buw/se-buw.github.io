A few steps are required to set up the development environment for the Xtext tutorials and to load the examples from the GitHub repository.


## Installation of Eclipse for Java and DSL Developers

{{< youtube id="navnb2wZPqU" >}}

See the [YouTube playlist](https://www.youtube.com/watch?v=navnb2wZPqU&list=PLGyeoukah9NbZzlK31hTH7oyZ8FRptT29&index=1) for all videos.

To follow the tutorials, you need to have Eclipse installed on your machine. Ideally, you install the latest version of Eclipse IDE for Java and DSL Developers, which includes the necessary tools for Xtext development. You can download it from the [Eclipse website](https://www.eclipse.org/downloads/).

## Cloning the Code Examples Repository

{{< youtube id="k26RsmAdA4o" >}}

See the [YouTube playlist](https://www.youtube.com/watch?v=k26RsmAdA4o&list=PLGyeoukah9NbZzlK31hTH7oyZ8FRptT29&index=2) for all videos.



The repository with the code examples for these [Xtext tutorials is available on GitHub](https://github.com/se-buw/xtext-intro). 

Once you have cloned the repository, you can import the projects into your Eclipse workspace. To do this, go to `File` > `Import...` > `Existing Projects into Workspace`. You may now select `Select root directory:`, and select the root directory of the cloned repository or one of the subdirectories `01.hellodsl`, `02.greetingsdsl`, or `03.turtle`. Make sure to check the projects you want to import and click `Finish`. Note that each of the three languages mentioned above requires all five projects in their respective directories to be imported.

After importing the projects, you need to run the MWE2 workflow to generate the necessary code to test the DSL or its tooling. To do this, select the `Generate<LanguageName>.mwe2` file in the `src` folder of the respective language project, e.g. project `org.xtext.example.hellodsl`. With a right-click select `Run As` > `MWE2 Workflow` from the context menu.
