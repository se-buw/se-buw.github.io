A few steps are required to set up the development environment for the Xtext tutorials and to load the examples from the GitHub repository.


## Installation of Eclipse for Java and DSL Developers

{{< youtube id="navnb2wZPqU" >}}

See the [YouTube playlist](https://www.youtube.com/watch?v=navnb2wZPqU&list=PLGyeoukah9NbZzlK31hTH7oyZ8FRptT29&index=1) for all videos.

To follow the tutorials, you need to have Eclipse installed on your machine. Ideally, you install the latest version of Eclipse IDE for Java and DSL Developers, which includes the necessary tools for Xtext development. You can download it from the [Eclipse website](https://www.eclipse.org/downloads/).

## Cloning the Code Examples Repository

The repository with the code examples for these [Xtext tutorials is available on GitHub](https://github.com/se-buw/xtext-intro).
