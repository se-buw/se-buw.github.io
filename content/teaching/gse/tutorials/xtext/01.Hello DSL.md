This project overview refers to folder `01.hellodsl` in the [code examples repository](https://github.com/se-buw/xtext-intro/tree/main/01.hellodsl). The grammar and code for code generation are quite small and the videos show how to create each from scratch. Thus, rather than browsing the final code, we recommend to watch the videos and follow along trying to replicate the steps.


## Creating an Xtext Project and Grammar

{{< youtube id="2nIe0IElS6A" >}}

See the [YouTube playlist](https://www.youtube.com/watch?v=2nIe0IElS6A&list=PLGyeoukah9NbZzlK31hTH7oyZ8FRptT29&index=2) for all videos.

To create an Xtext DSL we need to start by creating an Xtext project in Eclipse. It turns out that for the most common cases we obtain five rather than a single project all created by the project wizard. 

We select `File > New > Project... > Xtext > Xtext Project` and then follow the steps in the wizard. The first step is to select a `Project name` for the project.
