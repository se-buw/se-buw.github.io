**This site presents a collection of tutorials created for to the Generative Software Engineering (GSE) course at the [Bauhaus University Weimar.](https://www.uni-weimar.de)**
Not all tutorials are were taught in each iteration of the course. Up until Winter Semester 2025/26 we focused on the [Eclipse Modeling Framework (EMF) - Tutorial](tutorials/emf/) and the [Reactive Synthesis with Spectra - Tutorial](tutorials/spectra/) in the course and homework assignments. 

In Summer Semester 2026 this selection is increasing in order to offer more variety and to cover more topics in the field of generative software engineering. The aim of these tutorials is to introduce to the relevant technologies. However, there is a strong bias to quickly get started with code generation and to enable students to use the tools for their own Generative Software Engineering projects. 

Currently this site offers the following content:

- [Blockly - Tutorial](tutorials/blockly/)
- [Dafny - Tutorial](tutorials/dafny/)
- [Eclipse Modeling Framework (EMF) - Tutorial](tutorials/emf/)
- [Reactive Synthesis with Spectra - Tutorial](tutorials/spectra/)
- [Xtext - Tutorial](tutorials/xtext/)
