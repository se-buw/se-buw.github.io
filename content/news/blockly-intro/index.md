We have published a new tutorial that teaches how to define visual Blockly languages and code generators. The tutorial shows how to define new blocks for custom nocode and low-code languages. We then show how to define code generators in a block-wise manner. Finally, we adapt Blockly's built-in JavaScript code generator to generate code for a custom language inspired by the Logo programming language.

The tutorial comes with:
- A [step-by-step guide to defining visual Blockly languages and code generators](/teaching/gse/tutorials/blockly/).
- A complete [GitHub repository with all the code and examples](https://github.com/se-buw/blockly-intro) used in the tutorial.
- A [video walkthrough of the tutorial](https://www.youtube.com/watch?v=95_8n-FnHyo&list=PLGyeoukah9NbMQqFaMfuGMkAQ-yaaWUD3), explaining the concepts and demonstrating the implementation.

It joins our collection of tutorials on generative software engineering, including [Spectra for Reactive Synthesis](/teaching/gse/tutorials/spectra/0a.reactive-synthesis-with-spectra/) and [Ecore in the Eclipse Modeling Framework](/teaching/gse/tutorials/emf/).
